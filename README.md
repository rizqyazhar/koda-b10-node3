# Minitask

## Project Meminjam Buku

Aplikasi interaktif untuk peminjaman buku

### Capability

- User dapat melihat buku apa saja yang tersedia
- User dapat melakukan transaksi peminjaman

### Requirements

- NodeJS LTS
- IDE VSCODE

### How to run

1. Install Dependencies

```
npm install
```

2. Run the project using `npm run dev`

```
npm run dev
```
